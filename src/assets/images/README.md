# Assets - Images

## Logo Files

Place the QuizCraft logo files here:

- `logo.png` - Main logo (full color, transparent background)
- `logo-white.png` - White version for dark backgrounds (optional)
- `logo-icon.png` - Icon only version (for favicon, mobile)

**Recommended sizes:**
- Full logo: 200x60px or SVG
- Icon: 512x512px for favicon generation

The app currently references:
- `/src/assets/images/logo.png` - Used in Header component
- `/src/assets/images/logo-icon.png` - Used for favicon (optional)

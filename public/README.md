# Public Assets

## Favicon / Logo

Place your QuizCraft logo here as:
- `logo.png` or `logo.svg` - Will be used as the browser tab icon (favicon)

The favicon is referenced in `index.html` and will appear in:
- Browser tabs
- Bookmarks
- Browser history
- Mobile home screen shortcuts

**Recommended format:**
- SVG (scalable) or PNG
- Square aspect ratio (e.g., 512x512px)
- Transparent background
